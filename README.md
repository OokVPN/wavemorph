# WaveMorph

WaveMorph переносит динамическую амплитудную огибающую одного аудиофайла на другой. Исходный звук и его тембр сохраняются, а локальная громкость меняется так, чтобы повторять динамический рисунок референса.

## Возможности

- Два аудиофайла: исходник и референс.
- Перенос огибающей по нормализованной временной шкале, поэтому длительности могут различаться.
- Регулировка силы переноса и сглаживания.
- Прослушивание загруженных и обработанного файлов.
- Экспорт результата в WAV PCM 16-bit.
- Вся обработка выполняется локально в браузере. Аудио не отправляется на Vercel и не сохраняется на сервере.

Поддерживаемые форматы зависят от декодеров браузера: обычно WAV, MP3, M4A/AAC, OGG и FLAC. Максимальный размер файла — 60 МБ, длительность — 5 минут.

## Как работает перенос

WaveMorph вычисляет коротковременную RMS-огибающую исходника и референса с шагом 20 мс. Обе кривые сглаживаются, нормализуются по среднему уровню, а затем для каждого временного участка рассчитывается коэффициент усиления. Коэффициент применяется к исходной волне с интерполяцией между участками. В итоге меняется динамика исходного звука, а не его частотное содержимое.

Это перенос огибающей громкости, а не копирование отдельных циклов формы волны и не преобразование тембра. Результат зависит от исходного материала; при очень тихих участках усиление ограничивается, чтобы не поднимать шум без меры.

## Локальный запуск

Требуется Node.js 20.9 или новее (в GitHub Actions используется Node.js 24).

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

Проверка типов и production-сборка:

```bash
npm run typecheck
npm run build
npm start
```

## GitHub → Actions → Vercel

1. Создай пустой GitHub-репозиторий `wavemorph`.
2. Распакуй архив и загрузи всё содержимое проекта в корень репозитория.
3. Сделай commit в `main`. Workflow `.github/workflows/ci.yml` автоматически установит зависимости, проверит TypeScript и соберёт приложение.
4. В Vercel выбери **Add New → Project**, импортируй репозиторий.
5. Framework Preset: **Next.js**. Root Directory: `./`. Build Command и Output Directory оставь по умолчанию.
6. Нажми Deploy. Переменные окружения не нужны.

После подключения репозитория Vercel будет создавать деплой для push, а GitHub Actions — выполнять отдельную проверку сборки.

## Примечания

- Обработка требует современного браузера с Web Audio API.
- При больших файлах может потребоваться свободная оперативная память браузера.
- Длительности файлов могут отличаться: референс равномерно сопоставляется со всей временной шкалой исходника.
- Результат экспортируется в WAV, чтобы избежать потерь при повторном сжатии.
